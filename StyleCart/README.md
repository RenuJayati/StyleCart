# StyleCart 🛍️

StyleCart is a Django-based e-commerce web application where users can browse products, search and filter products by category, view product details, add products to cart, update cart quantities, and place orders.

## 🚀 Features

- Product listing
- Product search
- Category-wise product filtering
- Product detail page
- Add to cart
- Increase/decrease cart quantity
- Remove products from cart
- Checkout system
- Order placement
- Order success page
- Contact form
- Django Admin panel for product and order management
- Responsive and clean UI

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Django Templates
- Django ORM
